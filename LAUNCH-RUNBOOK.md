# Portafile — Day-1 Launch Runbook

One page, in order. The 30-day validation clock (03 §kill-gates) starts at step 4 — not before.
Everything below is stuff only a human can do; the agent's guardrails forbade all of it.

## Before posting anything (≈30 min, one sitting)

1. **Trademark knockout search** — go to https://tmsearch.uspto.gov, search "portafile" (live marks, classes 9 & 42). Known collision is physical office file-carriers (different class — fine). If a live software mark exists: stop, rename before posting (runner-up name: Dialbook, see 04).
2. **Fix the legal-page address** — `site/privacy.html` + `site/terms.html` say "San Francisco, California"; make it your real city/state (or remove the line), commit, push. Wrong jurisdiction on a live ToS is worse than none.
3. **Dry-run the demo path yourself on a phone and a laptop**: portafile.vercel.app → "Try it" → add a recipe → Print tab → new-hire pack. If anything confuses *you*, it will confuse an owner.

## Launch (day 1)

4. **Post #1 to r/barista** — copy from `extras/launch-posts.md` §1, replace `[link]`. Posting starts the 30-day clock: write today's date here: `____-__-__`.
5. **Open the founder dashboard** (localhost:4322) — log the post URL in the post tracker; check it twice a day and answer every comment for 48h using the comment-reply kit in launch-posts.md.

## Cadence (days 2–14)

6. Day 3: post #2 (money angle, r/cafe). Week 2: post #3 (roaster angle) — only after shop feedback exists to cite.
7. Log every content submission and prepay interest in the dashboard ledger as it happens, not from memory.

## The gates (day 30 — be ruthless)

- **15 owner content submissions** (recipes/dial-ins from real shops) — misses = kill or pivot.
- **10 prepays** ($99 founding-year pre-orders of sync) — individually fatal per 07; requires a Stripe account (payment link is enough; ~15 min; the one paid-adjacent step, still $0 until money moves *to* you).
- Day-30 engagement check: are day-1 signups still opening the app? (behavioral-moat gate from 07).

Miss a gate → read 03 §kill-criteria and follow it. That's what it's for.
